# Search glossary for bin/search.py.
#
# The district writes in its own vocabulary; people search in theirs. Each line
# maps a plain-language term to the phrases the documents actually use:
#
#   plain term: district phrase, district phrase
#
# A query containing the plain term (whole words, case-insensitive) is widened
# with the listed phrases. Add a line when a real question misses because of
# wording, and only list phrases that occur in text/ (grep first).
#
# Prefix a word with '=' to make it exact: it then matches only that literal
# word, bypassing the stemmer. Use it for short acronyms the stemmer would fold
# into ordinary words (unmarked, "ami" also matches every "Amy").
